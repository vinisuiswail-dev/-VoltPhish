# 🛡️ منصة محاكاة التصيد – النسخة الواقعية

## 📌 الوصف
منصة تدريبية احترافية لمحاكاة هجمات التصيد (Phishing) مصممة لتكون واقعية قدر الإمكان، بهدف تدريب الموظفين والمختصين على اكتشاف هجمات التصيد في بيئة آمنة وخاضعة للرقابة.

## ✨ الميزات الجديدة في النسخة الواقعية
- **تصميم احترافي** يعكس واجهات الخدمات الحقيقية.
- **شعارات ديناميكية** تتغير حسب الخدمة المختارة.
- **ألوان خاصة** بكل خدمة (Google, Instagram, eFootball).
- **تأخير واقعي** في إعادة التوجيه لمحاكاة معالجة الخادم.
- **تسجيل محاولات وهمية** لتعزيز واقعية التدريب.
- **تنسيق JSON** للسجلات لتسهيل التحليل.
- **حماية محسنة** ضد الوصول المباشر.

## ⚙️ المتطلبات
- خادم محلي (XAMPP / WAMP / LAMP)
- PHP 7.4 أو أحدث
- متصفح حديث

## 🚀 التثبيت والتشغيل
1. ضع جميع الملفات في مجلد واحد داخل `htdocs`.
2. شغل Apache عبر XAMPP.
3. افتح الرابط: `http://localhost/phishing-simulation/index.html`.
